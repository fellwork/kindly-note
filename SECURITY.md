# Security Policy

If you believe you have found a security vulnerability in this repository,
please do not open a public issue. Instead, report it privately through
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
feature on this repository (Security tab → "Report a vulnerability"), or
contact the repository owner directly.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any affected versions or components

We will acknowledge reports as soon as possible and work with you on a fix
and coordinated disclosure timeline.
