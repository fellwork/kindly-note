Initial release of `@kindly-note/lang-pack-ecmascript`: shared mode helpers and constant lists for the ECMAScript family (JSON / JS / TS / CoffeeScript / LiveScript). Exports `IDENT_RE`, `KEYWORDS`, `LITERALS`, `BUILT_INS`, `BUILT_IN_VARIABLES`, `EXTENDED_NUMBER_MODE`, and the `extendedNumberMode()` factory. All values are deep-frozen at module init (spec §0 architectural shift #2).
