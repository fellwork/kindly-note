# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build
tool that works with multi-package repos, or single-package repos to help you version and
publish your code. You can find the full documentation for it
[in our repository](https://github.com/changesets/changesets).

## Quickstart

Add a changeset for any PR that touches a `@kindly-note/*` package:

```sh
bunx changeset
```

Pick the affected package(s), the bump type (`patch` / `minor` / `major`), and write a one-line
summary. Commit the generated `.changeset/<name>.md` file alongside your code changes.

At release time, the maintainer runs `bunx changeset version` to roll up the pending changesets
into version bumps and CHANGELOG entries, then `bun run release` to publish.
